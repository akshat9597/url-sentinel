# ByteForce Supporting Material and Visual Assets

## Scope

The project package includes supporting visual references supplied during planning. They are not currently wired into the React application, detection pipeline, or deployment assets.

## Supplied references

- A white image containing abstract black marks and shapes.
- A photograph of a traditional Chinese lakeside pavilion.
- A close-up photograph of an orange flower.

## Product treatment

These references are not used as evidence, telemetry, threat indicators, or security controls. They should not be presented as screenshots of the ByteForce product or as generated training data. The current product interface uses its own dashboard styling and does not depend on these images.

If a future presentation or landing page uses them, they should be stored under a documented assets directory with usage rights and clear attribution where required. They should remain separate from security telemetry and machine-learning datasets.
